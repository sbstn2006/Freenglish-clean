# Sistema de Cursos - Freenglish

## ¿Cómo Están Organizadas las Páginas?

### 1. Página Principal de Cursos (`/cursos`)
- Muestra todos los cursos que hay disponibles
- Cada curso tiene un botón Ver más que me lleva a ver ese curso específico

### 2. Página de un Curso Específico (`/cursos/[curso]`)
- Muestra los niveles que tiene ese curso

### 3. Página de un Nivel Específico (`/cursos/[curso]/[nivel]`)
- Muestra los docentes que dan clases en ese nivel

## Cursos que Hay Disponibles

### 1. Inglés Básico (`ingles-basico`)
- Nivel A1 - Principiante: Lo más básico del inglés
- Nivel A2 - Elemental: Para empezar a hablar inglés básico

### 2. Inglés Intermedio (`ingles-intermedio`)
- Nivel B1 - Intermedio Bajo: Para hablar inglés en situaciones normales
- Nivel B2 - Intermedio Alto: Para conversaciones más complicadas

### 3. Inglés Avanzado (`ingles-avanzado`)
- Nivel C1 - Avanzado: Para usar inglés en trabajo o estudios
- Nivel C2 - Maestría: Nivel casi nativo
